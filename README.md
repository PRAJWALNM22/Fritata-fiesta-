# Frittata Fiesta Café (Egg AddA) 🍳

[![Netlify Status](https://api.netlify.com/api/v1/badges/4aaf580c-555e-464c-a325-0316986f8ddb/deploy-status)](https://app.netlify.com/projects/fritata-fiesta/deploys)

The official web experience for **Frittata Fiesta Café (Egg AddA)** — Bengaluru's premier egg specialty café serving 150+ innovative egg delicacies, from Italian slow-baked Frittatas to Surat Egg Ghotalas, Gourmet Omelettes, Sizzlers, and Rolls.

---

## 🌟 Key Highlights & Features

- **Interactive Digital Menu**: Filter 150+ curated dishes by category (Frittatas, Ghotalas, Gourmet Omelettes, Sizzlers, Rolls, Beverages, and more).
- **Dietary & Spicy Indicators**: High-protein highlights, spice level badges, and custom egg preparation tags.
- **WhatsApp Direct Ordering**: Instant order cart and direct ordering integration via WhatsApp.
- **Location & Dine-In Details**: Interactive map, opening hours, directions to Banashankari, Bengaluru.
- **Responsive & High-Performance Design**: Built with Vite, modern CSS styling, fluid animations, and mobile-first ergonomics.
- **SEO & Social Sharing Ready**: Rich OpenGraph tags, schema markup, and metadata.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm` (comes with Node.js)

### Installation

```bash
# Clone the repository
git clone https://github.com/PRAJWALNM22/Fritata-fiesta-.git

# Navigate into the project directory
cd "fritata fiesta"

# Install dependencies
npm install
```

### Local Development

Start the Vite development server with live reload:

```bash
npm run dev
```

Then open `http://localhost:5173` in your browser.

### Building for Production

To create an optimized production build in the `dist/` directory:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
